# FreightIQ Data Directory

All data generated by `generate_freight_data` is fictional, synthetic demo data. It is created from deterministic business rules and seed `20261022` by default, not copied from real carrier transactions. Company and product names are illustrative fictional identities; no record should be represented as a real commercial transaction.

- `master/` — optional input location for carrier, supplier, product, lane and rate-card CSVs.
- `transactions/` — optional invoice CSV input location.
- `ground_truth/` — separate anomaly labels produced by the exporter.
- `exports/` — CSV/JSON exports and `validation_report.json`.

Generate a compact dataset:

```powershell
python manage.py generate_freight_data --seed 20261022 --carriers 12 --shipments 100 --invoices 70
python manage.py validate_freight_data
python manage.py export_freight_data --directory data/exports
```

The `--reset` option removes only records marked synthetic. It does not delete unmarked operational records. Keep ground truth separate from ordinary invoice input data.
